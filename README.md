# BIDII-SCHOOL

## Project Description 
This project shows the students performance at BIDII-SCHOOL. It calculates the total marks scored by students against the mean,mode,
max and min per subject. It as displays the remarks of whether the students passed or failed based on the passmark.


## Technologies Used 
- Excel
- Github

## Dataset Used 
This project used data extracted from the performance of BIDII-SCHOOL students in the following 11 subjects:
1. Maths
2. English
3. Kiswahili
4. Biology
5. Chemistry
6. History
7. CRE
8. Geography
9. Computer
10. Homescience
11. Agriculture

## Challenges 
- Cleaning and organizing students data
- Uploading project files to github

  ## Findings
  - The best performed subject is Kiswahili
  - The highest maximum mark scored across the subjects is 98%
  - There is no correlation between the mean and the mode
  - Most of the students are doing averagely well with a few of them below the pass-mark and very few at the top
